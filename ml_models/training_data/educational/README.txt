Put educational video files here before training.

Examples of educational content:
- Lecture recordings (lecturer explaining a topic)
- Whiteboard or slide-based teaching videos
- Academic tutorials and demonstrations
- Course revision sessions

Supported formats: .mp4  .avi  .mov  .mkv  .webm

The more videos you add, the more accurate the model becomes.
Minimum recommended: 20 videos.

If you have the educational-content-detection-main GitHub dataset,
copy those educational video files into this folder.
